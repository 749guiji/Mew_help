# 第十章「多标签主题分类器」— 开发记录

## 阶段一:brainstorm 定稿(2026-11-21)

### 用户关键原话(需求要点)
- 用 Superpowers 给客服系统训练自己的模型:微调多标签主题分类器,把飞轮攒下的低置信度问题按主题批量归类,好决定先补哪块知识。六块:①数据处理四步(清洗/归并术语表/分层抽样 80-10-10/增强只扩训练集)②标注(多标签,大模型预标+人工抽审)③训练(RoBERTa-wwm-ext 全参微调、验证集盯分、正则化+早停)④评测(每类 P/R/F1+混淆矩阵+人工复核错例)⑤部署(ONNX+独立 FastAPI 推理服务,旁路批量归类写 topic_classifications,主链路不调)⑥前端(主题分布页等 7 个页面)。
- 17 类术语表:退换货/物流/尺码/发票 四类领头;边界:修归保修维修、退归退换货;运费管钱、物流管货;价保补差价、优惠券满减。
- 技术栈定死:哈工大讯飞 RoBERTa-wwm-ext 全参微调、ONNX+独立推理服务。不做 LoRA、embedding/意图微调。
- 训练算力本机直接跑;1700 条(增强前,每类 ~100)是实用底线;F1 = 调和平均、偏科惩罚重。
- 验收:①测试集每类 F1+混淆矩阵报告 ②真实问题归类、后台分布页看统计 ③「买大了想退」多诉求同中多类。

### 关键产出(侦查结论)
- 本机 **CPU-only**(torch 2.15.0+cpu,cuda False);`transformers==5.23.0`(大版本,API 需对着本机核对)。
- **HuggingFace 被墙**(000),**ModelScope 通**(302)→ 模型从 ModelScope 拉同款 hfl/chinese-roberta-wwm-ext。
- **飞轮池近乎空**(MySQL 没起、ch09 刚搭)→ 1700 条几乎全要靠 qwen3:8b 照术语表造模拟数据。
- HF 缓存里只有 bge-reranker-v2-m3,没有 roberta-wwm。

### 用户裁定(我抛出、用户拍板)
- 模型从 ModelScope 拉(替代被墙的 HF)。
- 训练数据几乎全模拟(真实样本个位数)。

- **验收「真实问题」= 手写样例 + 捞真实行**(不是纯合成)。
- **人工抽审/错例复核 = 事后复核,非训练前卡点**。

### 翻车与返工(按严重度)
- **ModelScope 无原 id(第一坑)**:`hfl/chinese-roberta-wwm-ext` 在 ModelScope 上 404,镜像 id 是 `dienstag/chinese-roberta-wwm-ext@v1.0.0`(同 HFL 权重);且是 **BERT 架构**(BertModel 加载,非 RobertaModel)。
- **transformers 5.x API 变了**:`from_pretrained` 无显式 `num_labels` → 用 AutoModel 裸编码器 + 手接 `nn.Linear(768,17)` 头;`transformers.AdamW` 没了 → `torch.optim.AdamW`。
- **Ollama 生成极慢**:qwen3:8b CPU 上 5 条/次约 2min,1700 条全量估计 2 小时以上 → 后台跑。

### 训练冒烟(代码路径验证)
- 手写 15 条切 10/2/3,1 epoch:loss 0.73、val_macro_f1 0.04、best.pt 落地 → 训练循环通了(分低只因数据只有 10 条)。

### 功能演示命令(完整流水线,按序)
```bash
# 1. 生成 1700 条模拟样本(需 Ollama,CPU 上很慢,约 2h+)
PYTHONPATH=. .venv/Scripts/python.exe -m ml.data.generate_synthetic

# 2. 建集(清洗→分层抽样→增强训练集→写 train/val/test.jsonl)
PYTHONPATH=. .venv/Scripts/python.exe -m ml.data.build_dataset

# 3. 全量训练(RoBERTa-wwm-ext 全参微调,早停,存 ml/artifacts/best.pt)
PYTHONPATH=. .venv/Scripts/python.exe -m ml.train

# 4. 评测(每类 P/R/F1 + 混淆矩阵 → ml/artifacts/eval_report.json)
PYTHONPATH=. .venv/Scripts/python.exe -m ml.eval

# 5. 导出 ONNX
PYTHONPATH=. .venv/Scripts/python.exe -m ml.export_onnx

# 6. 起独立推理服务(端口 8001)
.venv/Scripts/python.exe -m uvicorn inference.app:app --port 8001

# 7. 旁路批量归类(后台「跑主题归类」按钮,或)
curl -X POST http://127.0.0.1:8000/api/jobs/classify-topics/start
```
