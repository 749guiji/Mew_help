### 拒绝 / 纠偏

### 翻车与返工(根因)
- **现象**:`/extract` 首次 curl 120s 超时;真实 chain 复现时返回 `None`(而非 `AfterSalesExtraction`)。
- **根因**:`with_structured_output(method="function_calling")` 会**强制 `tool_choice` 指向具体函数**;qwen3.5:4b(4b 小模型)不遵守强制指令,把 JSON 写进文本 `content` 而非发 `tool_calls`,langchain 的 parser 只认 tool_calls → 返回 None。
- **佐证**:原始 llm 返回 `content='```json {...}```'`、`tool_calls=[]`、additional_kwargs 含 `refusal`。
- **对照实验**(直接 httpx 打 Ollama):`tool_choice="auto"` 5s 返回正确 tool_calls;`json_mode`/`json_schema` 正确但 85s(触发模型长推理);普通 prompt 73s。可行修复 `bind_tools(tool_choice="auto")` 实测 8s 正确。
- **决策**:用户选换 `qwen3:8b`(约 5GB,能进 8GB 显存),待下载完成后改 `.env` 的 `MODEL=qwen3:8b`、重启 uvicorn、重测验收 #3。
