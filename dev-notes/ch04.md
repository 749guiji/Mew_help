### 翻车与返工
- **Context7 文档误导**:官方 LangChain 集成文档明写「full-text search 不在 Milvus Lite,仅 Standalone/Distributed」,但这是针对旧版的说法;实测 milvus-lite 3.2.2 已支持 BM25 + hybrid_search + RRF。若不实测,会误判成「必须切 Standalone」。
- **Ollama 无 rerank 端点**:`POST /api/rerank` 返回 404,bge-reranker-v2-m3 也不在本地模型 → 重排不能在 Ollama 跑,只能 torch 承载(正是用户「技术选型定死、矛盾停下来问」的触发点,已停下来让用户拍板 A)。
- **analyzer 命名**:用户写「chinese analyzer」,实测 Lite 只认 `standard`/`jieba`,`chinese` 直接 `unknown tokenizer type`;中文分词实际是 `jieba`,需加 `jieba` 依赖(jieba 是 Lite 的内置中文 tokenizer)。
- **jieba 依赖安装网络抖动**:首次 `pip install jieba` 遇 ConnectionReset 重试,最终装成 0.42.1。
- 环境快照:Ollama 0.40.16(qwen3:8b + bge-m3 在库)、pymilvus 3.0.3 + milvus-lite 3.2.2、Python 3.14.7、Docker Desktop + MySQL(mew_help 6 表 + 16 chunks 全 done)。
