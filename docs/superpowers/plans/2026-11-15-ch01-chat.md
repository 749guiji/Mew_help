# 第一章「纯对话」实现计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 用 FastAPI + LangChain 跑通电商客服的纯对话闭环:SSE 流式多轮对话 + PromptTemplate 模板化 + with_structured_output 结构化提取 + 历史裁剪/token 预算。

**Architecture:** 分层 FastAPI 应用(`routers / schemas / services / prompts / core`)。应用侧统一 OpenAI 协议:单一 `ChatOpenAI` 从 `.env` 读 `base_url/model/api_key`,GPT/Claude/DeepSeek/Ollama 可换。多轮上下文用 `session_id` + 服务端内存会话;`/chat` 走 SSE 流式,`/extract` 走结构化 JSON。服务层依赖注入 LLM,单测用 fake,不碰真实模型。

**Tech Stack:** Python 3.14 · FastAPI 0.163 · uvicorn 0.54 · langchain 1.5 / langchain-core 1.8 / langchain-openai 1.8 · pydantic 2.14 · pydantic-settings 2.16 · tiktoken 0.14 · pytest + httpx。

**Spec:** `docs/superpowers/specs/2026-11-15-ch01-chat-design.md`

## Global Constraints

- Python ≥ 3.11(已在 3.14.7 验证全依赖可装)。
- 依赖版本以 `requirements.txt` 钉死为准:fastapi==0.163.1、uvicorn[standard]==0.54.0、langchain==1.5.0、langchain-core==1.8.1、langchain-openai==1.8.0、pydantic==2.14.3、pydantic-settings==2.16.3、tiktoken==0.14.0。
- `ChatOpenAI(model=..., base_url=..., api_key=...)`:其中 `base_url`/`api_key` 是别名(实际字段 `openai_api_base`/`openai_api_key`)。
- **结构化输出必须显式 `method="function_calling"`**——langchain 1.x 默认已改成 `json_schema`,第三方 OpenAI 兼容端点(Ollama/DeepSeek)不支持,必须显式指定。
- `llm.astream(messages)` 返回 `AsyncIterator[AIMessageChunk]`,取文本用 `chunk.content`。
- 全部模型配置走 `.env`(字段名大写,如 `MODEL`/`BASE_URL`/`API_KEY`),不硬编码。
- 中文枚举值:`request_type ∈ {退款,退货,换货,维修,物流查询,其他}`。

## Review Focus

1. **空/纯空白 message** → 应在 schema 层返回 422,不进入服务、不崩溃。
2. **未知 session_id** → 服务应新建会话(等同 None),不抛 KeyError。
3. **模型输出枚举外的 `request_type`** → Pydantic 应抛 `ValidationError`,接口返回明确错误,不静默放行。
4. **空流(模型一个 chunk 都不吐)** → SSE 仍以 `done` 收尾,不挂起。
5. **单条超长历史消息** → 裁剪必须保留最近消息且 token 不超预算,不抛异常。

### Task 5: 对话服务(流式 + 内存会话)

**Files:**
- Create: `app/services/chat_service.py`
- Test: `tests/test_chat_service.py`

**Interfaces:**
- Produces: `ChatService(llm: BaseChatModel | None = None)`;方法 `async stream_chat(self, session_id: str | None, message: str) -> AsyncIterator[dict[str, str]]`。
  - 事件流:`{"type":"meta","session_id":sid}`(首条)→ `{"type":"token","content":...}`(每条 chunk)→ `{"type":"done"}`(收尾);异常时 yield `{"type":"error","message":...}`。
  - 会话:内部 `dict[str, list[BaseMessage]]`;`session_id` 为 None 或不在 dict 中 → 新建(用 `uuid4().hex`);每轮把 user 消息与完整 assistant 回复追加进历史;构建消息用 `build_chat_messages(trim_history(...), message)`(裁剪用 `max_history_tokens`/`max_history_messages`)。

- [ ] **Step 1: 写失败测试** `tests/test_chat_service.py`

```python
import asyncio
from langchain_core.messages import AIMessageChunk
from app.services.chat_service import ChatService

class FakeLLM:
    def __init__(self, chunks): self.chunks = chunks; self.calls = []
    async def astream(self, messages):
        self.calls.append([m.content for m in messages])
        for c in self.chunks:
            yield AIMessageChunk(content=c)

async def collect(agen):
    return [x async for x in agen]

def test_stream_chat_emits_events():
    fake = FakeLLM(["你", "好"])
    svc = ChatService(fake)
    ev = asyncio.run(collect(svc.stream_chat(None, "你好")))
    assert ev[0]["type"] == "meta" and "session_id" in ev[0]
    assert [e["content"] for e in ev if e["type"] == "token"] == ["你", "好"]
    assert ev[-1]["type"] == "done"

def test_second_turn_receives_history():
    fake = FakeLLM(["收到"])
    svc = ChatService(fake)
    e1 = asyncio.run(collect(svc.stream_chat(None, "我的订单123没发货")))
    sid = e1[0]["session_id"]
    asyncio.run(collect(svc.stream_chat(sid, "那帮我催一下")))
    second = fake.calls[1]
    assert any("我的订单123没发货" in m for m in second)
    assert any("那帮我催一下" in m for m in second)

def test_unknown_session_id_starts_fresh():
    svc = ChatService(FakeLLM(["ok"]))
    ev = asyncio.run(collect(svc.stream_chat("no-such-id", "hi")))
    assert ev[0]["type"] == "meta"
    assert ev[0]["session_id"] != "no-such-id"

def test_empty_stream_still_done():
    svc = ChatService(FakeLLM([]))
    ev = asyncio.run(collect(svc.stream_chat(None, "hi")))
    assert ev[-1]["type"] == "done"
```

## Self-Review 结论(已自查)

- **Spec 覆盖**:四项目标各有对应任务——SSE 流式(Task 5/6)、PromptTemplate(Task 3)、with_structured_output(Task 4)、历史裁剪+token 预算(Task 2)。三条验收对应 Task 7。
- **Review Focus 5 条**:均已落测——空 message(Task 6 `test_chat_empty_message_422`)、未知 session_id(Task 5 `test_unknown_session_id_starts_fresh`)、非法枚举(Task 4 `test_schema_rejects_bad_enum`)、空流(Task 5 `test_empty_stream_still_done`)、超长历史(Task 2 `test_trim_history_token_budget`)。
- **类型一致**:`count_tokens`/`trim_history`/`get_llm`/`build_chat_messages`/`AfterSalesExtraction`/`ExtractionService`/`ChatService`/`create_app` 全计划内命名与签名一致。
- **比例**:计划长度与 spec 相当,代码块以测试断言 + 签名为主,无整段实现誊抄。
